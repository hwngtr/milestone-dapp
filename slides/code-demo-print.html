State machine

The deadline moves Funding to Active or Failed. deliver opens the challenge window. A money majority vetoes and cancels the campaign. release credits the creator after the window closes.

claimRefund() and withdraw()

// Campaign.sol:172-185, claimRefund()
ICampaign.Status current = _sync();
if (current == ICampaign.Status.Funding) revert DeadlineNotReached();
if (current == ICampaign.Status.Active || current == ICampaign.Status.Completed)
    revert GoalAlreadyReached();
uint256 amount = contributionOf[msg.sender];
if (amount == 0) revert NothingToWithdraw();
contributionOf[msg.sender] = 0;              // Effects first
refundsWithdrawn += amount;
(bool ok,) = msg.sender.call{value: amount}("");  // Interaction last
if (!ok) revert TransferFailed();
// Campaign.sol:190-197, withdraw() -- onlyCreator
uint256 amount = creatorCredit - creatorWithdrawn;
if (amount == 0) revert NothingToWithdraw();
creatorWithdrawn += amount;
(bool ok,) = msg.sender.call{value: amount}("");
if (!ok) revert TransferFailed();

Notes

  1. Both functions zero the claim before the external call. Re-entry sees a settled claim.
  2. Pull over push. The contract never sends ETH unprompted and never loops over donors.
  3. A second call reverts. Unclaimed refunds stay in the clone with no admin sweep.

Factory and clone

The factory validates the inputs, deploys a 45-byte EIP-1167 clone, and calls initialize in the same transaction. The clone holds donor ETH. The factory holds no campaign ETH.
